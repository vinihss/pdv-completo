# Instruções para Claude Code

Leia [`AGENTS.md`](AGENTS.md) para as regras globais e [`docs/README.md`](docs/README.md) para localizar a fonte adequada à tarefa. Carregue somente os guias necessários.

- Antes de editar, confira as instruções mais próximas dos arquivos-alvo.
- Para comportamento, comandos e estado atual, confira código, testes, manifests, scripts e CI. Não confie em contagens ou versões copiadas em docs.
- Se documentação e implementação divergirem em comportamento, dados ou segurança, registre a evidência e não escolha silenciosamente.
- A documentação não autoriza acesso a produção. Para tarefas de banco, siga `docs/agent-db-maintenance.md`; esclareça ambiente e autorização antes de qualquer operação real.
- Siga o protocolo de validação e relato de `AGENTS.md`.
